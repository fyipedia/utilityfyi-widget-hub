Quick Start

Embed unit converters, timezone clocks, holiday lists, and name analysis in one line of HTML.

<!-- Load any combination of utility widget scripts -->
<script src="https://cdn.jsdelivr.net/npm/unitfyi-embed@1/dist/embed.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/timefyi-embed@1/dist/embed.min.js"></script>

<!-- Drop widgets anywhere -->
<div data-unitfyi="entity" data-slug="meter"></div>
<div data-timefyi="entity" data-slug="asia-seoul"></div>

FAQ

What units does UnitFYI support?

UnitFYI supports 220 units across 20 categories: length, mass, volume, area, temperature, pressure, energy, power, force, speed, time, frequency, data, data-rate, currency, fuel-economy, angle, illuminance, and electric. Decimal precision via BigNumber. Browse categories or use the converter.

How many timezones does TimeFYI cover?

TimeFYI covers all 600+ IANA timezone names + 25K+ cities. Each timezone has DST rules, UTC offset, current time, sunrise/sunset (where applicable), and business hours calculation. World clock view shows multiple cities simultaneously.

Which countries do HolidayFYI widgets cover?

HolidayFYI covers 200+ countries with public + religious holidays. Includes Easter calculation, lunar holiday lookup (Chinese New Year, Korean Chuseok, Hindu festivals), regional variations (US state-specific, German bundesland). Browse countries.

Why does NameFYI focus on Korean names?

NameFYI specializes in Korean name romanization (4 systems): Revised Romanization, McCune-Reischauer, Yale, North Korean. Plus Five Elements (Wuxing) name analysis + CJK stroke counts. Try the romanizer or Five Elements analyzer.

Are widget calculations accurate to high precision?

Yes. UnitFYI uses BigNumber for arbitrary-precision arithmetic. TimeFYI uses Luxon for timezone math. HolidayFYI uses precomputed lunar tables to 2100. NameFYI Five Elements use deterministic stroke-count algorithm. No floating-point artifacts.
